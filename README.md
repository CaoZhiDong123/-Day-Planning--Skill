# 军师 Skill

一个基于 Markdown 的每日任务管理 AI skill。融合「游戏化任务清单」+「上朝复命机制」，帮你管理每天的学习/工作节奏。

**上朝**：开工前运行，AI 读取你的任务看板，整理出今日该做什么、优先级怎么排。
**复命**：收工时运行，你用自然语言说今天做了什么，AI 自动更新看板和日志。

所有数据存储在本地 Markdown 文件中，不依赖任何在线服务。

---

## 特性

- 🎭 **人设驱动**：军师/主公的角色扮演，欢快老道，天天督促干活
- 🏰 **三级任务体系**：主线任务 + 日常任务 + 活动任务（含考试倒计时）
- 🔆 **上朝模式**（只读）：自动检测日常重置、逾期告警、倒计时计算、时间块分配建议
- 🌙 **复命模式**（读写）：自然语言汇报进展 → 自动更新看板 + 写日报 + 同步 HTML
- 📊 **双文件同步**：MD + HTML 两份卷宗自动保持一致
- 🎯 **考试冲刺模式**：倒计时分级（🔴🟡🟢），逾期自动告警
- 📝 **日报/周报/月报**：自动提醒撰写，晚报自动生成日报
- ⚙️ **零配置上手**：首次使用对话式引导，支持 Obsidian 和纯 Markdown 用户

## 安装

将 `军师.md` 放到你的 AI 工具的 skill/命令 目录下即可。

### Claude Code

```bash
# 放入项目级命令目录（推荐）
cp 军师.md your-project/.claude/commands/军师.md

# 或放入全局命令目录（所有项目可用）
cp 军师.md ~/.claude/commands/军师.md
```

### 其他 AI 工具

大部分支持自定义 prompt/skill 的 AI 工具都可以使用。核心要求：
1. 能读取本地文件
2. 能写入/编辑本地文件
3. 能将 Markdown 内容作为 system prompt 或 skill 加载

## 使用方式

### 首次使用

第一次运行时，AI 会询问你的任务文件路径、称呼偏好等，然后基于你现有的任务清单开始工作。如果没有任务清单，军师会引导你创建。

### 日常使用

**早上开工（上朝）：**
```
/军师 上朝
```
或直接说「上朝」「早朝」。军师会翻阅你的任务卷宗，献上今日锦囊——包含优先级排序、时间块建议、逾期告警和倒计时提醒。

**晚上收工（复命）：**
```
/军师 复命 今天完成了XX，YY还没做完因为...
```
或直接说「复命」然后描述今天做了什么。军师会更新任务状态、写日报、同步 HTML。

**修改配置：**
```
/军师 重新配置
```
修改称呼、语气偏好、数据路径等。

### 调用语法说明

上面的 `/军师` 是 Claude Code 的 slash command 语法。其他工具的调用方式可能不同：
- 如果你的工具支持 slash command，使用 `/军师`
- 如果不支持，直接在对话中说「上朝」或「复命」，skill 能从上下文判断模式

## 人物设定

军师是一个经验老道、阅人无数的谋士，说话风格：
- 🎭 **欢快老道**：聪明通透，但嘴上没把门的
- 🔥 **热情有力**：主人完成任务使劲夸，偷懒就拐弯抹角损
- ⚡ **频繁督促**：带催促、带调侃、带激将法
- 😏 **偶尔毒舌**：像老朋友，不真冒犯

称呼用户为「主公」或「主公大人」，自称「老夫」「老臣」。

## 常见问题

**Q: 我需要同时维护 MD 和 HTML 两份文件吗？**
A: 不需要。军师会自动同步两份文件，你只需要跟军师对话即可。

**Q: 我不用 Obsidian，可以用吗？**
A: 完全可以。军师使用纯 Markdown 文件，不依赖任何特定笔记工具。

**Q: 任务清单文件可以手动编辑吗？**
A: 可以。看板就是普通 Markdown，你随时可以手动改。军师下次读取时会识别你的修改。

**Q: 日常任务忘了重置怎么办？**
A: 上朝时军师会自动检测 daily-reset 日期，过期了会醒目提醒并询问是否重置。

**Q: 考试结束了任务还在怎么办？**
A: 军师会自动检测已过期的活动任务，主动提醒你归档。
